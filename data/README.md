# Data

The notebook expects a policy PDF in the working directory
(original run: `Company-Policy-and-Procedure-June-1.18-V6.0.pdf`, a corporate policy document from TriageLogic).

The PDF is **not** included in this repository. To run the notebook on your own document:
1. Put your PDF here (or next to the notebook).
2. Change the file name in the `PyPDFLoader(...)` call.
3. Replace the 10 golden questions and reference answers with questions about your document.
